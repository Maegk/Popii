Creative Fatigue Detection System

AI-Powered Ad Performance Monitoring

1

Install Docker Desktop

Download and install Docker Desktop from docker.com

2

Start Docker Desktop

Make sure Docker Desktop is running (you'll see the Docker icon in your system tray)

3

Run the Startup Script

Windows: Double-click start.bat
Mac/Linux: Double-click start.sh (or run ./start.sh in terminal)

4

Wait for Startup

The application will start automatically (takes 30-60 seconds). Your browser will open when ready.

📍 Quick Links:
• Frontend UI: http://localhost:3000
• Backend API: http://localhost:8000
• API Documentation: http://localhost:8000/docs

⚠️ Important: Make sure Docker Desktop is running before clicking "Open Application". If the application doesn't open, run the startup script first (start.bat or start.sh).
